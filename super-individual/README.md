首页采用近白画布、墨蓝文字与钴蓝交互，突出作品大图、标题层级和阅读留白。首屏可在两个项目间切换，作品截图以缩略图选择；研究证据仍可放大，首页原型过程稿与心理剧场截图采用静态展示，避免把阅读入口误认为交互原型。同时支持四种学生场景切换、五组竞品机制与设计取舍切换、方法与认证证据展开、摘要复制和打印 / 存为 PDF。证据页配有桌面章节目录、手机折叠目录与当前章节提示。图解和场景推演用于解释设计判断，不代表学生原话或已验证的用户效果。

首页新增五组真实研究画面：完整体验地图、产品理解与策略、竞品机制与取舍、情感化与 IP、方案与验证准备，可切换、放大并进入完整成果。研究档案收录 2026 年 6 月基础、7—9 月阶段成果及 10 月后续深化；历史提案、当前决策、设计推演和测试准备分别标明。35 是阅读入口数，截图、重复文件和三件套子方案不另计数量。0706 测试套装为 16 个 HTML 路径，按内容去重 14 份；该套装以代表性工具入口呈现。

心理剧场展示的是 2026-09-23 已批准并集成的“人格配方”真实详情角色动效。进入预览区域后自动播放，可暂停、重播或拖动进度；离开预览区域或页面进入后台后暂停。直接打开本地 HTML 也可运行。该网页预览不替代 Android Pad / WebView 实机验收。

打印时会展示全部截图、场景、竞品与折叠证据，并用静态画面替代动效。页面支持键盘操作：切换组可用方向键、Home、End，选中项在手机横向列表中保持可见；放大图片后用 Escape 关闭及焦点恢复。导航、按钮、缩略图与展开项提供一致反馈，用户触发的切换采用短转场，并尊重系统的减少动态偏好。

## 推送到 GitHub 后获得在线链接

1. 将**本目录的完整内容**放到你选定仓库的根目录，保留 `assets/`、`evidence/` 与 `research/`，不要只上传一个 HTML。
2. 在仓库 **Settings → Pages** 选择 **Deploy from a branch**。
3. 选择已推送的分支和 **/(root)**，保存后等待发布。
4. 使用 Pages 界面实际显示的网页地址作为申报材料链接。仓库地址或 HTML 源码地址不等于网页预览地址。
5. 用无登录状态的浏览器核对首页、研究档案、完整阅读副本与三份证据页可访问、图片可加载，再填写申报表。

此处未预填账号、仓库或在线地址。GitHub Pages 的可用性和访问范围依账户、仓库与组织设置而定；如组织只允许内部展示，可将同一静态目录放到已授权的内网站点。
